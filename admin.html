Google Analytics

ভিজিটর ও কনভার্সন ট্র্যাক করার জন্য

কী করে: কতজন ভিজিটর আসে, কোথা থেকে আসে, কী দেখে, কী কেনে — সব ডেটা পাবেন। সম্পূর্ণ ফ্রি।

1

analytics.google.com-এ যান

আপনার Gmail account দিয়ে sign in করুন।

Open Analytics
2

Account তৈরি করুন

Admin (নিচে বাম দিকে) → Create Account → Account name: Heartix

3

Property তৈরি করুন

Property name: Heartix, Time zone: Bangladesh, Currency: BDT

4

Data Stream যোগ করুন

Platform: Web, Website URL: heartix.vercel.app

5

Measurement ID কপি করুন

G- দিয়ে শুরু একটা ID দেখাবে। কপি করুন।

6

Heartix Admin-এ paste করুন

Settings → Integrations → Google Analytics → Enable + ID paste → Save।
